# Obsidian Templates

> All templates require the use of the [Templater](https://community.obsidian.md/plugins/templater-obsidian) community plugin.

I currently have a `Templates` folder in the root of my Obsidian vault with these templates. 

## Templater settings
- Template folder location: Templates
- Automatic jump to cursor: toggled ON
- Trigger Templater on new file creation: toggled ON (used for enabling folder templates)
- Enable folder templates: toggled ON
  - I have respective folders for each template file. 
  For example, I have a `Dream logs` folder, which I apply the `Dream Log Template.md` file to. This makes it so any file created in the `Dream logs` file automatically get templated upon file creation!
